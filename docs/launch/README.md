# Launch material

Drafts for announcing 0.1.0, kept with the docs so they change with them.
They are not part of the published site (`mkdocs.yml` excludes this
directory). Check every number against the release before posting.

| File | For |
|---|---|
| [announcement.md](announcement.md) | the release post, about 400 words |
| [hacker-news.md](hacker-news.md) | a Show HN title and the first comment |
| [ruby-weekly.md](ruby-weekly.md) | a Ruby Weekly submission |
| [reddit.md](reddit.md) | posts for r/ruby and r/devops |
| [lightning-talk.md](lightning-talk.md) | a 10-minute talk with a live demo script |
